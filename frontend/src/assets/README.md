# Provenance des assets

Ces PNG sont des copies intégrales, sans retouche, du ZIP graphique fourni pour TOQ. Les sources restent intactes sous `base/Charte graphique-20260922T132420Z-1-001/Charte graphique/`.

| Fichier frontend | Source dans la charte |
| --- | --- |
| `toq-logo.png` | `Logos/ChatGPT Image 21 sept. 2026, 16_06_32.png` |
| `toqi-welcome.png` | `assets TOQi/Capture d_écran 2026-09-21 161808.png` |

Le fond blanc opaque des sources est intégré à la palette crème via CSS (`mix-blend-mode: multiply`), sans réécriture des PNG. Le logo conserve son slogan d’origine. Les icônes de section sont des SVG simples écrits dans le composant React ; elles ne remplacent pas les assets de marque. Les illustrations portent un texte alternatif, les icônes décoratives sont ignorées par les lecteurs d’écran.
